# 🌿 Botanical Herbarium

A personal digital archive documenting plant species through botanical photography, descriptions, and visual storytelling.

### ✨ Features
- Botanical specimen collection
- Plant descriptions and field notes
- Collection statistics
- CSS animations and hover effects
- Responsive layouts

### 🛠️ Built With
- HTML5
- CSS3
- Flexbox & Grid
- CSS Animations
